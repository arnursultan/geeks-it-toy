# IT Той — приглашение

Небольшой сайт-приглашение на IT Той от Geeks в Оше. На странице есть анимированный конверт, информация о событии и
площадке, направления обучения, обратный отсчёт и контакты.

## Запуск

Нужен Node.js и npm. В папке проекта выполните:

```bash
npm install
npm run dev
```

Vite покажет адрес локального сайта в терминале (`http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

## Где менять данные события

Дата, время, место и контактная информация собраны в `src/config.ts`. Таймер использует дату и время оттуда.
